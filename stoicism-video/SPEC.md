# SPEC — "Stoicism in 90 Seconds" (HyperFrames, vertical short)

The single source of truth for every agent working on this film. Read it fully before writing a line.

## Format
- 1080×1920, 30 fps, total **93.26 s** (root `data-duration`). Vertical TikTok / Reels / Shorts.
- Timings for every scene + every spoken word (scene-local seconds): `script/scenes.json`.
- Narration (already mixed, one file): `assets/voice/narration.wav` (voice: Kokoro `am_michael`, American male).
- Root composition: `index.html` (owned by the Task Manager). Scenes: `compositions/<scene-id>.html`. Captions: `compositions/captions.html`.

## Story (the one idea)
Stoicism = **separate what you control from what you don't**, then act on the first and let go of the rest. Three rules, three Stoics, one everyday example each, ending on one question: *"Is this in my control?"*

## Look — "Bronze & Marble at night"
| Token | Value | Use |
| --- | --- | --- |
| `--ground` | `#0D0B09` | warm black background (set by root; scenes stay transparent over it) |
| `--marble` | `#EFE8DA` | primary text / ivory |
| `--dim` | `#8E8476` | secondary text, "let go" elements |
| `--gold` | `#E0A84A` | **in your control**, emphasis, rule numerals |
| `--ember` | `#D9573E` | **not in your control**, "story", fear, anger |
| `--stone` | `#1C1915` | cards / panels fill |
| `--line` | `#3A332B` | hairlines, card borders |

- Display face: **Playfair Display** (700, 900, italic 700) — headlines, quotes, names, Roman numerals.
- Label / UI face: **Inter** (700, 900) — labels, chips, UI mockups, uppercase tracking `0.08em` for small labels.
- No other fonts, no emoji (no emoji font in the renderer), no external images or network fetches. Draw icons as inline SVG (simple, geometric, 6–8 px strokes, round caps).
- Cards: `--stone` fill, 2 px `--line` border, radius 28 px, no drop shadows except a soft gold glow on the one "hero" element of a scene (`0 0 60px rgba(224,168,74,.25)`).
- Banned defaults: centered bullet slides, three equal cards in a row, icons in circles, generic gradient blobs, stock "tech" blue, Lorem-style filler.

## Layout (platform safe zones)
- Nothing readable above **y = 200** (status bar / app chrome).
- Scene visuals live in the band **y = 220 … 1080**. Keep x inside **90 … 990** (action-safe).
- **y = 1120 … 1340 is reserved for captions** (owned by the captions worker). Scenes put NOTHING readable there or below. Below 1340 only subtle decoration (fine for a scene to leave empty).
- Minimum readable text size 34 px; headlines 90–150 px; Roman numerals up to 420 px.
- Vertical stacking, one subject at a time, centered column.

## Motion language (numbers, not adjectives)
- Entrance: `fromTo` opacity 0→1, y +40→0, `filter: blur(10px)→blur(0px)`, 0.45 s, `power4.out`.
- Emphasis punch: scale 1→1.08→1 over 0.35 s (`back.out(3)` up, `power2.out` down).
- Strike-through: a 10 px `--ember` bar scaling `scaleX 0→1` from the left, 0.3 s `power3.inOut`.
- Exit: opacity →0 + y −30, 0.25 s `power2.in`, ending ≥0.05 s before the scene's end.
- Ambient life: the hero element drifts (scale 1→1.03 or y ±8 px) across the whole scene with `sine.inOut`, so no frame is ever static >1.5 s.
- **The voice is the clock**: every element appears within ±0.15 s of the word that names it (use `words[].start` from `script/scenes.json`). Never reveal something before it is said (the scene title/numeral may lead by ≤0.3 s).
- A new visual beat every 2–4 s.
- First frame of the film (t=0) must already show the hook line — never black.

## HyperFrames contract (must pass `npx hyperframes lint` and `check`)
- Scene file = everything inside `<template>`; root element `<div id="root" data-composition-id="<scene-id>" data-width="1080" data-height="1920">` styled as `#root { position:absolute; inset:0; }`.
- Every timed element: `class="clip"`, `id`, `data-start`, `data-duration` (scene-local seconds, inside the scene's duration).
- One paused timeline: `const tl = gsap.timeline({ paused: true }); … window.__timelines["<scene-id>"] = tl;` registered after the tweens.
- Use `fromTo` (not `from`). Never tween `display`/`visibility`/`autoAlpha` on a `.clip` — animate a child or opacity of a child. No CSS `transform` on an element GSAP transforms. No `Date.now()`, no `Math.random()`, no timers, no `repeat:-1`.
- Prefix every id with the scene short name (`s3-pile-left`) — ids must be unique across the film.
- Timed elements are written in HTML (not generated by script). Copy goes in the HTML.
- GSAP is provided by the root; scenes don't load scripts.

## Captions (compositions/captions.html, id `captions`)
- Spans the whole film (0 → 93.26). Words from `script/words_global.json` (global seconds). Clean punctuation for display (strip trailing commas/periods; keep `?`).
- Trending "word-pop" style: groups of 2–3 words, Inter 900, uppercase, 76 px (fit with max width 900 px, min 52), `--marble` with a 6 px dark stroke/shadow for legibility; the **currently spoken word turns gold and scales 1.12**.
- Group block sits centered at y ≈ 1180–1300 (inside the reserved band). One group visible at a time; each group hard-killed at its end (`tl.set(group,{opacity:0, visibility:"hidden"}, end)`).
- Host gets `data-track-kind="captions"`.
